## Overview

The .001 events files store raw event and waveform data for OSCAR sleep sessions. Each file represents one sleep session and contains multiple channels (e.g., pressure, flow rate, SpO2, events like apneas).

**Key Characteristics:**
- Binary format using Qt's QDataStream serialization
- Little-endian byte order
- Optional qCompress compression
- Version-dependent field availability
- Self-describing structure with metadata

---

## File Structure

```
┌────────────────────────────────────────┐
│  HEADER (42 bytes for version ≥ 10)    │
├────────────────────────────────────────┤
│  DATA BLOCK                            │
│  (compressed or uncompressed)          │
│                                        │
│  ┌───────────────────────────────────┐ │
│  │ Channel Count (qint16)            │ │
│  ├───────────────────────────────────┤ │
│  │ METADATA SECTION:                 │ │
│  │  - Channel 1 Metadata             │ │
│  │  - Channel 2 Metadata             │ │
│  │  - ...                            │ │
│  ├───────────────────────────────────┤ │
│  │ RAW DATA SECTION:                 │ │
│  │  - Channel 1 Raw Data             │ │
│  │  - Channel 2 Raw Data             │ │
│  │  - ...                            │ │
│  └───────────────────────────────────┘ │
└────────────────────────────────────────┘
```

## Data Types and Byte Order

**All values are little-endian (least significant byte first)**

| Type    | Size | Description                    | Example      |
|---------|------|--------------------------------|--------------|
| quint8  | 1    | Unsigned 8-bit integer         | 0-255        |
| qint8   | 1    | Signed 8-bit integer           | -128 to 127  |
| quint16 | 2    | Unsigned 16-bit integer        | 0-65535      |
| qint16  | 2    | Signed 16-bit integer          | -32768 to 32767 |
| quint32 | 4    | Unsigned 32-bit integer        | 0-4294967295 |
| qint32  | 4    | Signed 32-bit integer          | ±2 billion   |
| qint64  | 8    | Signed 64-bit integer          | Large values |
| double  | 8    | IEEE 754 double precision      | Floating point |
| bool    | 1    | Boolean (0=false, 1=true)      | 0 or 1       |
| QString | var  | Qt string (see QString section)| "cmH2O"      |

## Header Format

**All values in little-endian byte order**

```
Offset  Size  Type     Field Name          Description
------  ----  -------  ------------------  ----------------------------------
0       4     quint32  magic               Magic number (validate on read)
4       2     quint16  version             File format version (10 current)
6       2     quint16  fileType            File type (1 = event data)
8       4     quint32  machineId           Machine/Device ID
12      4     quint32  sessionId           Session ID (Unix timestamp)
16      8     qint64   sessionStart        Start time (ms since Unix epoch)
24      8     qint64   sessionEnd          End time (ms since Unix epoch)
32      2     quint16  compressionMethod   0=none, 1=qCompress
34      2     quint16  machineType         Device type enum
36      4     qint32   uncompressedSize    Size of data block when decompressed
40      2     quint16  crc16               CRC16 checksum of uncompressed data
```

**Header Reading Example (C-style):**

```c
uint32_t magic;
uint16_t version, fileType, compressionMethod, machineType, crc16;
uint32_t machineId, sessionId;
int64_t sessionStart, sessionEnd;
int32_t uncompressedSize;

// Read header (42 bytes)
fread(&magic, 4, 1, file);
fread(&version, 2, 1, file);
fread(&fileType, 2, 1, file);
fread(&machineId, 4, 1, file);
fread(&sessionId, 4, 1, file);
fread(&sessionStart, 8, 1, file);
fread(&sessionEnd, 8, 1, file);
fread(&compressionMethod, 2, 1, file);
fread(&machineType, 2, 1, file);
fread(&uncompressedSize, 4, 1, file);
fread(&crc16, 2, 1, file);

// Validate
if (fileType != 1) {
    printf("Error: Not an events file\n");
}
if (version < 6) {
    printf("Error: File version too old\n");
}
```

## Data Block Structure

### 1. Decompress if Needed

If `compressionMethod > 0`, decompress the entire data block using Qt's qCompress format (which is zlib with a 4-byte size header).

**Python decompression example:**
```python
import zlib
import struct

if compression_method > 0:
    # Read compressed data
    compressed_data = file.read()
    
    # Qt prepends uncompressed size as big-endian uint32
    size = struct.unpack('>I', compressed_data[:4])[0]
    
    # Decompress (skip first 4 bytes)
    data_bytes = zlib.decompress(compressed_data[4:])
else:
    data_bytes = file.read()
```

### 2. Parse Data Block

The data block has two main sections:

#### Section 1: Metadata for All Channels

```
┌────────────────────────────────────────────┐
│ channelCount (qint16)                      │
├────────────────────────────────────────────┤
│ FOR EACH CHANNEL:                          │
│  ├─ channelId (quint32)                    │
│  ├─ eventListCount (qint16)                │
│  └─ FOR EACH EVENTLIST:                    │
│      ├─ first (qint64)          8 bytes    │
│      ├─ last (qint64)           8 bytes    │
│      ├─ count (qint32)          4 bytes    │
│      ├─ type (qint8)            1 byte     │
│      ├─ rate (double)           8 bytes    │
│      ├─ gain (double)           8 bytes    │
│      ├─ offset (double)         8 bytes    │
│      ├─ min (double)            8 bytes    │
│      ├─ max (double)            8 bytes    │
│      ├─ dimension (QString)     variable   │
│      ├─ hasSecondField (bool)   1 byte     │
│      └─ IF hasSecondField:                 │
│          ├─ min2 (double)       8 bytes    │
│          └─ max2 (double)       8 bytes    │
└────────────────────────────────────────────┘
```

#### Section 2: Raw Data for All Channels

Data appears in the **same order** as the metadata section:

```
┌───────────────────────────────────────────┐
│ FOR EACH CHANNEL (in same order):         │
│  FOR EACH EVENTLIST (in same order):      │
│   ├─ Primary data array:                  │
│   │   count × 2 bytes (qint16 values)     │
│   ├─ IF hasSecondField:                   │
│   │   Second data array:                  │
│   │   count × 2 bytes (qint16 values)     │
│   └─ IF type != Waveform (type != 1):     │
│       Time delta array:                   │
│       count × 4 bytes (quint32 values)    │
└───────────────────────────────────────────┘
```

**Critical:** You must track the order of channels and EventLists from the metadata section to correctly parse the raw data section!

## QString Serialization

Qt's QString serialization format:

```
┌──────────────────────────────────────┐
│ size (qint32)  - number of uint16s   │
├──────────────────────────────────────┤
│ utf16_data     - size × 2 bytes      │
│ (UTF-16 encoded characters)          │
└──────────────────────────────────────┘
```

**Reading QString (Python example):**

```python
def read_qstring(data, offset):
    # Read size (number of UTF-16 characters, not bytes)
    size = struct.unpack('<i', data[offset:offset+4])[0]
    offset += 4
    
    if size == -1:  # Null string
        return "", offset
    
    # Read UTF-16 characters (little-endian)
    char_bytes = size * 2
    utf16_data = data[offset:offset+char_bytes]
    offset += char_bytes
    
    # Decode UTF-16LE to string
    string = utf16_data.decode('utf-16-le')
    
    return string, offset
```

**Note:** A QString can be "null" (size = -1), which is different from an empty string (size = 0).

## EventList Types

EventListType is a qint8 enum:

| Value | Name          | Description                                    | Has Time Array? |
|-------|---------------|------------------------------------------------|-----------------|
| 0     | EVL_Event     | Discrete events (apneas, arousals, etc.)       | Yes             |
| 1     | EVL_Waveform  | Continuous waveform data (flow, pressure, etc.)| No              |
| 2     | EVL_Gain      | Gain changes                                   | Yes             |
| 3     | EVL_Sum       | Accumulated values                             | Yes             |
| 4     | EVL_Span      | Time spans (mask on/off)                       | Yes             |

**Important:**
- **Waveforms (type 1)** do NOT have a time delta array - timestamps are calculated from `first`, `last`, and `rate`
- **Events (type 0)** have a time delta array where each value is milliseconds from the previous event

|------------------|-------------------|----------------------------|

| 0x10110002       | CPAP_FlowRate     | Flow rate waveform         |
| 0x10110003       | CPAP_MaskPressure | Mask pressure              |

| 0x10120002       | CPAP_Hypopnea     | Hypopnea events            |
| 0x10120003       | CPAP_ClearAirway  | Central apnea events       |
| 0x10120004       | CPAP_Apnea        | Unspecified apnea events   |
| 0x10140001       | CPAP_LeakTotal    | Total leak                 |
| 0x20110001       | OXI_Pulse         | Pulse rate (oximeter)      |

## Compression

OSCAR uses Qt's `qCompress()` which wraps zlib compression with a 4-byte big-endian header containing the uncompressed size.

**qCompress Format:**
```
┌─────────────────────────────────────┐
│ Uncompressed size (4 bytes, BE)     │
├─────────────────────────────────────┤
│ zlib compressed data                │
│ (RFC 1950 format)                   │
└─────────────────────────────────────┘
```

**Python decompression:**

```python
import zlib
import struct

def qUncompress(data):
    # First 4 bytes are big-endian uncompressed size
    expected_size = struct.unpack('>I', data[:4])[0]
    
    # Decompress the rest
    decompressed = zlib.decompress(data[4:])
    
    # Verify size
    if len(decompressed) != expected_size:
        raise ValueError("Decompression size mismatch")
    
    return decompressed
```

## Data Interpretation

### Timestamps

1. **Session-relative timestamps:** EventList `first` and `last` are milliseconds from session start
2. **Absolute timestamps:** Add `sessionStart` (from header) to get Unix epoch milliseconds
3. **Event timestamps:** For type 0 (Event), calculate cumulative sum of time deltas

### Data Values

Raw data values are stored as signed 16-bit integers. Convert to real values:

```
actual_value = (raw_value × gain) + offset
```

**Example:**
```
raw_value = 1234 (from data array)
gain = 0.01
offset = 0.0

actual_value = 1234 × 0.01 + 0.0 = 12.34 cmH2O
```

### Waveform Sampling

For waveform data (type 1), samples are evenly spaced:

```
sample_time[i] = first + (i × rate)
```

Where:
- `first` = start time (milliseconds)
- `rate` = milliseconds per sample
- `i` = sample index (0 to count-1)

**Example:**

```
first = 1000
rate = 20  (50 Hz = 1000ms / 50 = 20ms per sample)
count = 100

sample_time[0] = 1000
sample_time[1] = 1020
sample_time[2] = 1040
...
sample_time[99] = 2980
```

### Event Timing

For event data (type 0), time deltas are cumulative:

```
event_time[0] = first + time_delta[0]
event_time[1] = event_time[0] + time_delta[1]
event_time[2] = event_time[1] + time_delta[2]
...
```

**Example:**
```
first = 5000
time_delta[] = [100, 250, 180, ...]

event_time[0] = 5000 + 100 = 5100
event_time[1] = 5100 + 250 = 5350
event_time[2] = 5350 + 180 = 5530
```

### Second Field

Some EventLists have a second data field (e.g., for events with duration). If `hasSecondField` is true:
- Read `min2` and `max2` from metadata
- Read second data array (same size as primary)
- Apply the same gain/offset formula

## Pseudocode Examples

### Complete File Parser

```python
def parse_oscar_events_file(filename):
    with open(filename, 'rb') as f:
        # Read header
        header = read_header(f)
        
        # Read and decompress data block
        data_block = f.read()
        if header['compressionMethod'] > 0:
            data_block = qUncompress(data_block)
        
        # Parse data block
        channels = parse_data_block(data_block, header)
        
        return header, channels

def read_header(f):
    header = {}
    header['magic'] = read_uint32(f)
    header['version'] = read_uint16(f)
    header['fileType'] = read_uint16(f)
    header['machineId'] = read_uint32(f)
    header['sessionId'] = read_uint32(f)
    header['sessionStart'] = read_int64(f)
    header['sessionEnd'] = read_int64(f)
    header['compressionMethod'] = read_uint16(f)
    header['machineType'] = read_uint16(f)
    header['uncompressedSize'] = read_int32(f)
    header['crc16'] = read_uint16(f)
    return header

def parse_data_block(data, header):
    offset = 0
    channels = []
    
    # Read channel count
    channel_count, offset = read_int16(data, offset)
    
    # PHASE 1: Read all metadata
    metadata_list = []
    for i in range(channel_count):
        channel_id, offset = read_uint32(data, offset)
        eventlist_count, offset = read_int16(data, offset)
        
        eventlists = []
        for j in range(eventlist_count):
            el = {}
            el['first'], offset = read_int64(data, offset)
            el['last'], offset = read_int64(data, offset)
            el['count'], offset = read_int32(data, offset)
            el['type'], offset = read_int8(data, offset)
            el['rate'], offset = read_double(data, offset)
            el['gain'], offset = read_double(data, offset)
            el['offset'], offset = read_double(data, offset)
            el['min'], offset = read_double(data, offset)
            el['max'], offset = read_double(data, offset)
            el['dimension'], offset = read_qstring(data, offset)
            el['hasSecondField'], offset = read_bool(data, offset)
            
            if el['hasSecondField']:
                el['min2'], offset = read_double(data, offset)
                el['max2'], offset = read_double(data, offset)
            
            eventlists.append(el)
        
        metadata_list.append({
            'channelId': channel_id,
            'eventlists': eventlists
        })
    
    # PHASE 2: Read all raw data (in same order!)
    for channel_meta in metadata_list:
        channel_id = channel_meta['channelId']
        eventlists = channel_meta['eventlists']
        
        for el_meta in eventlists:
            count = el_meta['count']
            el_type = el_meta['type']
            
            # Read primary data array
            primary_data, offset = read_int16_array(data, offset, count)
            el_meta['data'] = primary_data
            
            # Read second field if present
            if el_meta['hasSecondField']:
                second_data, offset = read_int16_array(data, offset, count)
                el_meta['data2'] = second_data
            
            # Read time deltas for non-waveform types
            if el_type != 1:  # Not waveform
                time_deltas, offset = read_uint32_array(data, offset, count)
                el_meta['time_deltas'] = time_deltas
        
        channels.append({
            'channelId': channel_id,
            'eventlists': eventlists
        })
    
    return channels
```

### Extract Specific Channel

```python
def extract_pressure_data(channels, session_start):
    """Extract CPAP pressure waveform data"""
    CPAP_Pressure = 0x10110001
    
    for channel in channels:
        if channel['channelId'] == CPAP_Pressure:
            for eventlist in channel['eventlists']:
                if eventlist['type'] == 1:  # Waveform
                    # Calculate timestamps
                    count = eventlist['count']
                    first = eventlist['first']
                    rate = eventlist['rate']
                    gain = eventlist['gain']
                    offset_val = eventlist['offset']
                    
                    timestamps = []
                    values = []
                    
                    for i in range(count):
                        # Timestamp (absolute)
                        time_ms = session_start + first + (i * rate)
                        timestamp = datetime.fromtimestamp(time_ms / 1000.0)
                        timestamps.append(timestamp)
                        
                        # Value (converted)
                        raw = eventlist['data'][i]
                        value = (raw * gain) + offset_val
                        values.append(value)
                    
                    return timestamps, values
    
    return None, None
```

### Extract Events

```python
def extract_apnea_events(channels, session_start):
    """Extract obstructive apnea events"""
    CPAP_Obstructive = 0x10120001
    
    for channel in channels:
        if channel['channelId'] == CPAP_Obstructive:
            events = []
            
            for eventlist in channel['eventlists']:
                if eventlist['type'] == 0:  # Event type
                    count = eventlist['count']
                    first = eventlist['first']
                    time_deltas = eventlist['time_deltas']
                    data = eventlist['data']
                    gain = eventlist['gain']
                    
                    # Calculate cumulative timestamps
                    current_time = first
                    for i in range(count):
                        current_time += time_deltas[i]
                        
                        # Absolute timestamp
                        abs_time_ms = session_start + current_time
                        timestamp = datetime.fromtimestamp(abs_time_ms / 1000.0)
                        
                        # Event duration (if data represents duration)
                        duration_sec = (data[i] * gain)
                        
                        events.append({
                            'timestamp': timestamp,
                            'duration': duration_sec
                        })
            
            return events
    
    return []
```

## Common Pitfalls

### 1. Byte Order Confusion
**Problem:** Reading multi-byte values in the wrong endianness.  
**Solution:** Always use little-endian for data values, big-endian only for qCompress header.

### 2. QString Size Misunderstanding
**Problem:** Treating QString size as byte count instead of character count.  
**Solution:** Size is the number of UTF-16 characters. Multiply by 2 for byte count.

### 3. Data Section Ordering
**Problem:** Reading raw data arrays out of order from metadata.  
**Solution:** Store metadata in a list and iterate in the exact same order for raw data.

### 4. Waveform Time Calculation
**Problem:** Looking for time delta array in waveform data.  
**Solution:** Waveforms (type 1) don't have time arrays. Calculate from first, rate, and index.

### 5. Second Field Detection
**Problem:** Reading second field when it doesn't exist.  
**Solution:** Always check `hasSecondField` before reading min2, max2, and data2.

### 6. Null QString Handling
**Problem:** Not handling QString with size = -1.  
**Solution:** Check for size == -1 (null string) before reading UTF-16 data.

### 7. CRC Validation
**Problem:** Not validating decompressed data.  
**Solution:** If compression is used, verify CRC16 and size match expected values.

### 8. Session Time Conversion
**Problem:** Forgetting to add session start time to relative timestamps.  
**Solution:** EventList times are relative to session start. Add sessionStart for absolute times.

## Validation Checklist

When implementing a parser, verify:

- [ ] Header magic number matches expected value
- [ ] File type is 1 (events file)
- [ ] Version is >= 6 (preferably >= 10)
- [ ] Decompression size matches uncompressedSize field
- [ ] CRC16 validates (if compression used)
- [ ] Channel count matches actual channels read
- [ ] EventList count for each channel matches
- [ ] Data array sizes match count values
- [ ] Second field only read when hasSecondField is true
- [ ] Time arrays only read for non-waveform types
- [ ] All QString lengths handled correctly
- [ ] Byte offsets advance correctly throughout parsing
