# .001 Events File Format Documentation

The .001 events files store raw event and waveform data for OSCAR sleep sessions. These files use Qt's QDataStream format with little-endian byte order and Qt 4.6 compatibility. All data types follow Qt's serialization conventions.

## File Structure Overview

1. __Header__ (fixed size: 42 bytes for version ≥ 10, 32 bytes for older versions)
2. __Compressed/Uncompressed Data Block__

## Header Format (All values in little-endian byte order)

```javascript
Offset  Size  Type     Description
------  ----  -------  -----------------------------------------------
0       4     quint32  Magic number (constant value, verify matches expected)
4       2     quint16  File format version
6       2     quint16  File type (1 = event data)
8       4     quint32  Machine ID
12      4     quint32  Session ID
16      8     qint64   Session start time (milliseconds since Unix epoch)
24      8     qint64   Session end time (milliseconds since Unix epoch)
32      2     quint16  Compression method (0 = none, 1 = qCompress)
34      2     quint16  Machine type
36      4     qint32   Uncompressed data size (for validation)
40      2     quint16  CRC16 checksum of uncompressed data
```

## Data Block Format

If compression method > 0, decompress the data block using `qUncompress()` before parsing. Otherwise, parse directly.

### Data Block Structure:

1. Number of channels (qint16)

2. For each channel:

   - Channel ID (quint32)
   - Number of EventLists for this channel (qint16)
   - For each EventList: Metadata block

3. For each channel:
   - For each EventList: Raw data block

### EventList Metadata Block:

```javascript
Size     Type     Description
-------  -------  -----------------------------------------------
8        qint64   First timestamp (milliseconds since session start)
8        qint64   Last timestamp (milliseconds since session start)
4        qint32   Number of data points
1        qint8    EventList type (0=Event, 1=Waveform, etc.)
8        double   Sample rate (samples per second for waveforms)
8        double   Gain multiplier
8        double   Offset value
8        double   Minimum value
8        double   Maximum value
variable QString  Units/dimension string
1        bool     Has second data field
*if hasSecondField:*
8        double   Second field minimum
8        double   Second field maximum
```

### EventList Raw Data Block:

- __Primary data array:__ `count × 2` bytes (qint16 values, little-endian)
- __If hasSecondField:__ Second data array: `count × 2` bytes (qint16 values)
- __If type != Waveform:__ Time delta array: `count × 4` bytes (quint32 values, milliseconds)

## Data Interpretation

- __Timestamps:__ Add session start time to EventList first/last times to get absolute timestamps
- __Data Values:__ Apply formula: `actual_value = (raw_value × gain) + offset`
- __Time Deltas:__ For events, cumulative sum of deltas gives absolute time within EventList
- __Waveforms:__ Data points are evenly spaced at the specified rate from first to last time
- __Second Field:__ Additional data channel (e.g., for complex events)

## Implementation Notes

- All multi-byte values are little-endian
- QString serialization includes length prefix + UTF-16 data
- Validate CRC16 checksum after decompression
- Channel IDs map to predefined schema constants
- File version determines available fields (version ≥ 7 adds hasSecondField, etc.)

This format allows extraction of raw sleep data without OSCAR's codebase by parsing the binary structure according to the specifications above.
