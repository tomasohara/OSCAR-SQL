This project is to revise the bmc_loader (not the bmcg3x_loader). We need to re-reverse engineer the data as the existing loader does not give good results.

All investigations, work files, and notes should be in the Notes/Luna directory.
There are several folders in the Luna directory, all beginning with the letters "BMC". These are SD card images from different machines.

The file BMC_Legacy_File_Formats.md contains an estimated description of the file formats, as derived from existing code. Please update it as we go along.
