Changes and fixes in OSCAR v2.0 beta 2
Portions of OSCAR are © 2019-2026 by The OSCAR Team

  • [new] Support for Yuwell YH-580, YH-690, YH-830 CPAP
  • [new] Support for ReactHealth/BMC G3 and G3X CPAP (experimental)
  • [new] Allow user to change profile name
  • [fix] Profile preferences are now imported properly from OSCAR 1.x
  • [fix] Changed profile preferences now saved and restored properly
  • [fix] Notes added to Daily/Notes page are now saved
  • [fix] Crash on exit when using Ubuntu 24
  • [fix] Deleting a profile folder from disk could cause OSCAR to crash later
  • [fix] Box for Notes when printing Daily page is sized appropriately
  • [fix] DST change caused data loss in BMC loader
  • [fix] Date on Welcome page is translated properly
  • [fix] Prevent data loss on import if database is locked by another program
  • [fix] Export to CSV report tree view now saved correctly across dialog re-opening
  • [fix] Welcome page now legible when system is in dark mode
  • [fix] Crash in Overview page if mouse moves over no data
  • [fix] Data/Advanced purged data was reappearing after OSCAR restart
  • [fix] Rebuild from backup was destroying backup data in BMC loaders
  • [fix] Preferences Dialog "older than" date mangled when translated
  • [fix] OK and Cancel buttons not translated on one messagebox and several file dialogs
  • [fix] Oximetry importers now work
  • [updated] Translations for French, German
  • [updated] Fix assorted translation issues
